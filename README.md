# breakoutchrono
**Breakout Chrono** est une variante du célèbre casse-briques jouable directement dans le navigateur. Dans ce jeu, vous devrez lutter contre le temps pour venir à bout du mur de briques. Chaque niveau renferme son lot de surprises, comme des blocs spéciaux et toutes sortes de capsules qui vous aideront ou vous compliqueront la tâche. Arriverez-vous à casser toutes les briques avant que le chronomètre n'atteigne zéro ? 
A vous de jouer ! 

## Comment joeur ?
Après avoir cloné le dépôt dans un dossier de votre choix, ouvre un terminal dans ce dossier, et tapez la commande suivante pour installer les dépendances du projet :

    npm install

Ensuite, lancez l'application dans votre navigateur à l'aide de la commande suivante :

    npm run preview
